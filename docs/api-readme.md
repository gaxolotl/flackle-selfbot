# flackle-selfbot API reference

Generated from the public exports in `src/`. Use the search box or the sidebar to
browse every class, interface, type alias, variable and function.

For task-oriented guides — authentication, messages, reactions, servers,
permissions, gateway events, recipes and troubleshooting — use the **Docs home**
link in the header.

## Main entry points

| Symbol | What it is |
| --- | --- |
| `FlackleClient` | High-level client: login, gateway, messages, servers, conversations, account |
| `RestClient` | Cookie/CSRF-aware HTTP client |
| `Gateway` | Realtime WebSocket protocol |
| `PermissionFlags` | Permission bit values |
| `computePermissions` | Effective permission calculator |
| `Message` | Message payload |
| `Server` | Server payload |
| `Channel` | Channel payload |
| `Conversation` | DM/group payload |

> This library is unofficial and not affiliated with Flackle.
